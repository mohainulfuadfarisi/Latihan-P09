# Latihan P09 — Katalog Karya (Edisi Pustaka UI)

Repositori latihan pemanasan **Tugas P09 — Project Akhir Sprint 1: Project Charter dan Pustaka UI** pada mata kuliah **Praktikum Pemrograman Visual** (`3 D3 MM B`).

## Tujuan Latihan
Mendiagnosis dan memperbaiki masalah pemasangan pustaka UI (**Bootstrap 5.3.3**) pada aplikasi **Katalog Karya** menggunakan peramban dan DevTools (Elements, Console, Network, Responsive Design Mode).

## Cara Menjalankan
1. *Clone* atau buka folder latihan di **Visual Studio Code**.
2. Buka `index.html` melalui peramban (pastikan terhubung ke internet untuk memuat aset Bootstrap 5.3.3 dari CDN).
3. Buka DevTools (`F12`) dan Responsive Design Mode (`Ctrl+Shift+M`) untuk menguji tampilan dan perilaku komponen.
